Mental Health Status Detection from Text

This project uses machine learning and text analysis to explore how different mental health statuses (such as depression, anxiety, stress, and suicidal ideation) are expressed through language in online posts. The goal is to identify status-specific words and visualize them using word clouds, helping differentiate similar mental health conditions. 

Dataset: Sentiment Analysis for Mental Health (Kaggle) \
Features: statement, status \
Course: STATS 201
